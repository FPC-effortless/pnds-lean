# Compulsory TAC-OSM mathematical engineering, representation and formulation rule

**Scope:** every historical or prospective TAC-OSM architecture, variant, training candidate, decoder, memory upgrade and evaluation-only adapter. **Effective:** 2026-10-24. This is an additive research gate, not retroactive certification. It preserves every original failure and checkpoint.

**Two repositories, one version contract.** [PNDS](https://github.com/FPC-effortless/pnds-lean/pull/5) is the mathematical representation/formulation/formal-verification authority; [TAC-OSM](https://github.com/FPC-effortless/TAC-OSM/pull/387) owns original source, actual computation graph, authentic data, fits, checkpoints, reproducible measured outcomes and negative findings. The exact historical cross-links live in `foundation/v1/variant-math-links.json` and the identical reciprocal `TAC-OSM/research/pnds-variant-math-links.json`. **Commit SHA**, never a moving branch alone, identifies TAC experiment source.

## Non-negotiable research gate: MATHEMATICAL-ENGINEERING-REQUIRED

1. **Representation before optimization.** Define variant ID and ancestry, typed input/output and missingness, action timing/observability, state dimensions and units, entity identity, time semantics, conditioning versus intervention, probability measures, write/retain/read/forget paths, losses and invariants. Record full causal computational graph from observation to prediction/decision/feedback with explicit tensor shapes and gradient paths. Do not force one shared state tensor or replace native TAC with an SSM.
2. **Two formulations for each variant.** Maintain a named **Lean 4** module/definition with precise assumptions, propositions, proofs and deliberately OPEN obligations **and** an executable **Python mathematical reference** for the same operators/state transitions, with edge-case and randomized numerical tests. Neither a prose equation alone nor a shared kernel without full model semantics satisfies the whole-model gate. No `sorry`, `admit`, unreviewed axiom, or vacuous theorem may be counted as proved.
3. **Explicit correspondence.** Link the Lean declarations, Python reference, and exact TAC-OSM original source SHA/path in both repositories for **every variant**. Verify equations against real tensor layout and actual PyTorch source with shape/time/leakage checks, forward and backward/gradient checks, finite-precision tolerance, missing-data and mask checks, serial/parallel equivalence and exact error logs. If source mapping is incomplete mark `OPEN`; do not claim verified.
4. **Mathematical analysis.** Derive representation sufficiency limits; memory boundedness **versus information survival**; stability, contraction or counterexample; long-history interference; dynamics and action conditioning; normalization and calibration assumptions; causality/identifiability; active decision loss; operation count, memory complexity and legal batch/time/entity/scan parallelism. Validate initial/boundary cases and gradients. Formal guarantees apply **only** under their theorem hypotheses.
5. **Proof/evidence release gates.** Each new or changed variant needs (i) versioned spec + 2 linked formulations, (ii) passing Lean kernel build/axiom audit and Python mathematical tests, (iii) original-source numerical and gradient equivalence with immutable tolerances, (iv) evidence-ledger update preserving negatives. New capability/real-world superiority claims separately require authentic independent observations, equal data/parameter/training-compute comparisons and untouched held-out results; matching CPU wall-time is **not** compulsory.
6. **Append-only evolution.** Preserve old variants and prior research, inherited mathematical propositions and negative findings; add a new ID for changed source semantics. Amend variant links in *both* repositories and reject mismatched ID/SHA/operator statuses. Missing formalization is an explicit research blocker, never silently substituted or grandfathered into a proof.

## Implementation and verification

- `PNDS/TACOSMVariantContracts.lean` contains the cross-variant indexed formal contracts and limited exact mathematical claims; `PNDS/UnifiedTACOSM.lean` contains previously proved shared exact-real kernels.
- `foundation/v1/variant_math.py` supplies executable **reference-only** kernels, not reconstructed trained PyTorch. `foundation/v1/variant-math-links.json` binds them to each source-pinned version. Local validators/tests reject omissions and unauthorized upgrades.
- `TAC-OSM/research/pnds-variant-math-links.json` is a reciprocal snapshot; its presence by itself is **not** online proof of parity. Both manifests must be reviewed together at change/release time.
- The indexed 17 versions are currently **PARTIAL_SHARED_KERNEL_NOT_WHOLE_MODEL** even where a shared Lean scalar/affine theorem is proved. Historical models are not blocked from being cited truthfully; **new mathematical-readiness claims are blocked** until the complete model is formalized and source-checked.
- The inventory is explicitly partial historically; `archive-gaps.json` tracks outstanding legacy migrations. Negative experimental gates and strict replay failures retain their original labels.

**Do not conflate** Lean algebraic proof, Python reference validity, trained-source equivalence, real-world prediction, causal usefulness or commercial value.

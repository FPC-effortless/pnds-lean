# TAC-OSM unified mathematical research foundation — v1.0.0

**Owner of mathematical definitions:** PNDS. **Owner of implementations, model training, checkpoint bytes and authentic experimental evidence:** [TAC-OSM](https://github.com/FPC-effortless/TAC-OSM). This foundation does NOT create a second AI model, merge experimental branches, or treat Lean compilation as evidence of learned intelligence.

This is a **versioned, non-destructive overlay** on the existing PNDS v0.2 Lean formalization. The original v0.2 theorems and the open PNDS representation, information-bounds and TAC-OSM memory-contract PRs are retained *by reference*; no theorem or negative experiment has been rewritten or declared superseded without review.

## Contract and provenance

- `registry.json`: typed family/variant inventory, exact source repository, original Git commit, PR and relevant original code/evidence path. A branch link is only navigation; the **commit** pins its version. `candidate`, `trained_exposed_dev`, `math_candidate`, and `interface_only` are different kinds of evidence. No family automatically inherits another family's result.
- `evidence-ledger.jsonl`: append-only observations with immutable IDs, **including failures, negative results, unsupported assumptions, missing real tests and strict numerical verification failures**. Original scores and binary checkpoints remain on their original TAC-OSM branches; this registry is a **lossless provenance index**, not a second mutable score database or a full archive copy.
- `operator-contracts.json`: stable, version-to-equation source map and precise assumptions, verified theorem names, open properties and numerical obligations.
- `original-pr-snapshot.jsonl`: source-header snapshot of **375** historical TAC-OSM pull requests including original head SHAs and status. This is not a claim every fitted checkpoint/result was copied.
- `ARCHITECTURE.md`: shared computational-graph *interfaces* with lane-specific state spaces. **There is no universal state shape** or automatically causal action operator. See specified transitions separately.
- `PROOF_OBLIGATIONS.md`: explicit closed/open theorem contracts, proof assumptions, numerical and source equivalence, parallel legality, experimental gates.
- `PNDS/UnifiedTACOSM.lean`: limited, useful exact-real arithmetic proofs: affine transition associative composition and serial/scan equivalence at two steps, scalar gated retention-error identity, survival/activity normalization under assumptions, and explicit research-evidence claim-tier separation. **These do not prove any trained PyTorch graph or global memory capacity.**
- `scripts/validate_foundation.py` and `tests/test_foundation.py`: deterministic source-independent registry/schema/evidence references and anti-overclaim checks; CI requires these and the Lean axiom audit.

## Research role split

```text
PNDS:   mathematical specification -> assumptions -> Lean/analytic proof -> numerical verification obligation
           |                                                           ^
           v                                                           |
TAC-OSM: source implementation -> guarded parameters -> original fit -> real-data baseline -> failure/success
```

Core native (DIAGKEY004), System 1, full physical (ME080–095), enterprise (ME069–074), Temporal, Edge-Lite, Counterfactual and ES-WAM each retain their own state, output law, evidence and gate. `core` and `system1` are **not interchangeable**; ES-WAM 256-frame windowed selective memory is not indefinitely carried recurrent memory.

## Promotion rules

Mathematically proved ≠ compiled implementation ≠ synthetic mechanism diagnostic ≠ exposed authentic DEV ≠ independent authentic TEST ≠ demonstrated action benefit ≠ commercial deployment. Every new trained model retains the live **95k–105k useful trained/deployed parameter range**, **<=1% within compared model counts**, equal real-data presentation and **training compute** for fair architecture claims. Matching CPU wall-clock runtime is **not** mandatory. Synthetic tests have **zero authority** to establish real-world prediction or commercial value. Retrospective source EOR is not verified real workflow completion. No model is authorized to act on devices or Woyengi by this foundation.

## Preservation and completeness

This first release explicitly indexes the active lines and named negative/results milestones as of October 24, 2026. **It is not a claim that every historical DEV/ME/DIAGKEY/ES-WAM experiment has already been enumerated individually.** `archive-gaps.json` keeps their uncovered historical ranges as open migration obligations rather than silently dropping them. All original branches, PRs, scores, model weights and prior PNDS definitions stay untouched. A new research version must **append** a record with a new stable ID and parent IDs; never edit or delete a negative result to make a gate appear successful.

A source-implementation-to-theorem equivalence is **unverified until source code, tensor shapes, normalization and finite-precision behavior are matched and externally replayed**. A Lean theorem about real arithmetic does not prove PyTorch FP32/FP64 behavior.
